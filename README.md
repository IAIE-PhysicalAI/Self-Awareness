# Self-Awareness

**Competence Before Generation, Confidence After: A Two-Stage Self-awareness Framework for Large Language Models**

Institute of AI for Engineering, Tongji University.

Project homepage: https://iaie-physicalai.github.io/Self-Awareness/
Repository: https://github.com/IAIE-PhysicalAI/Self-Awareness

This repository contains the static project website, public preprint PDF, and original paper figures. Research code will be made publicly available separately. No arXiv identifier has been assigned yet.

The result cards show changes against the KB baseline, with explicit evaluation scope. Table values are rounded to three decimals for readability; hover to see the original paper values. The PDF keeps the original metric precision.
